Wyarden

A board in VS Code for work you hand to a coding agent.

What it is for

Wyarden keeps coding-agent tasks on one board. Each task is a card with its prompt, its session, and its status. The edits stay in that card’s own Git worktree until you decide they belong in the project.

A small fix can stay on one card. A larger job can be split into subtasks. A coordinated run can wait until you approve its plan and its limits.

How a task moves

  1. Open the repository as a saved workspace. The folder has to be the top of a Git repository, with a first commit.
  2. Add a card with a title and a prompt. Wyarden creates a branch and a worktree for it. A subtask branches from its parent.
  3. The card runs on Claude Code, Codex, Grok, or Antigravity, with the provider’s own CLI and the account you already signed in to. You pick the provider, and the model and effort it offers, per card.
  4. Follow the card through Running, Needs input, and Review. Open the session to answer a question or send a follow-up. Stop the work when you want it stopped.
  5. Read the reply, look at the changes, and look at any checks. Review means the turn ended. You decide whether the result meets the task.
  6. Merge brings committed work back into the project locally. Finish shows a plan that can commit, integrate, push, and remove the worktree. You confirm that plan. Mark done closes the card and leaves the branch where it is.

What else is on the board

  • The session and the review controls sit on the card, next to the task.
  • Saved assignments can run with dependencies and checks. A card can delegate only inside a plan and limits you approve.
  • You can dictate a prompt. Local Whisper and Local Parakeet run on your machine. OpenAI, Groq, and Deepgram use a speech key you set yourself.

Wyarden runs in VS Code on Windows and in VSCodium on Linux. It does not install the agent, sign you in, or pay for the model.
