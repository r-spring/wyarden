Wyarden

A live 3D view of what Claude Code is doing across your open editor windows.

See calls as they happen

Wyarden connects agents and subagents to the tools, files, URLs, and MCP servers they use. Select an editor window to focus on one project or choose All open to see them together.

Download the preview · Read the user guide

Get started

  1. Download the VSIX. In VS Code or a compatible VSCodium build, run Extensions: Install from VSIX and select the file.
  2. Open a local folder and start a signed-in Claude Code session there. Ask Claude Code to read a file.
  3. Click 3D Monitor in the status bar. Select the chip for that window to view the session.

Explore the source

The preview reads Claude Code session files and transcripts locally. See the Wyarden repository for the live extension, simulated browser preview, and development notes.
